# Data usage and provenance

This project studies public restaurant listings and ratings collected from Google
Places, Tripadvisor, and TheFork for an academic Data Management course. The project
is independent and is not affiliated with, endorsed by, or sponsored by those
platforms.

## What the repository publishes

The showcase branch publishes:

- a small integrated sample with no review text, reviewer profile, or contact fields;
- aggregate quality metrics, calibration evidence, and research results;
- schemas and code needed to understand or reproduce the pipeline with data obtained
  lawfully by the user.

Complete acquisition and processing outputs are excluded from the showcase tree. The
course-submission snapshot remains on the dated backup branch for project audit and
team recovery.

## Rights and responsibilities

The repository's MIT license covers the original source code and documentation. It
does **not** grant rights over platform names, trademarks, API responses, listing
content, reviews, reviewer data, photographs, or other third-party material.

Anyone collecting fresh data is responsible for complying with the applicable API
terms, website terms, robots directives, rate limits, privacy law, and local law. Use
official APIs where available, collect only what is necessary, avoid personal data,
and do not use the project to evade access controls.

The samples and metrics are a time-bounded 2026 academic snapshot. They are provided
for review, education, and reproducibility research without warranty. They must not be
treated as current restaurant recommendations or as an authoritative copy of any
platform's data.

For a public derivative, prefer publishing schemas, code, aggregate results, and a
similarly minimized sample. Do not republish the archived complete datasets unless you
have independently confirmed that you have the necessary rights and a lawful basis.
